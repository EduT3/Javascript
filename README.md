## Executar

Abra `index.html` no navegador ou sirva a pasta com `python -m http.server 8000` e acesse `http://localhost:8000`. Não há dependências npm.

## Roteiro

1. Comparação de valores e tipos (abra o console com F12).
2. Conversa com nome, idade e linguagem.
3. Escolha de área de desenvolvimento.
4. Jogo de adivinhação.
5. Lista de compras por categoria.
6. Referência à remoção de itens implementada no dia 5.
7. Calculadora com quatro operações e números decimais.

As páginas são exercícios independentes; dados não são persistidos. Os links relativos permitem abrir o projeto em subpastas.

## Casos de verificação

- Calculadora: `1,5 + 2,5`, número vazio, texto inválido, operação desconhecida e divisão por zero.
- Compras: cancelar o prompt, categoria inválida, adicionar/remover e digitar “sim” novamente sem apagar a lista.
- Navegar por teclado e abrir a página inicial em tela estreita.

O repositório preserva o propósito didático dos sete desafios, sem backend ou autenticação.
